# StudyMate – AI Student Task Manager

## Project Overview
StudyMate is a student productivity web application developed to help students manage assignments, organize study schedules and monitor academic progress.

## Features
- Interactive student dashboard
- Add, update and delete assignments
- Task priority management
- Deadline tracking
- Rule-based smart study planner
- Task completion analytics
- CSV report download

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas

## Installation

1. Clone the repository:

   `git clone YOUR_GITHUB_REPOSITORY_URL`

2. Open the project folder.

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`

## Project Purpose
This project was developed to improve student productivity and demonstrate Python application development, database integration and data visualization skills.
